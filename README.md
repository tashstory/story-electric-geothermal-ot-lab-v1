# story-electric-geothermal-ot-lab-v1
An interactive 3D geothermal power plant for learning how OT and IT run, connect and are secured. Walk the plant, operate the HMI, trace packets, edit firewall rules, follow Kerberos and MFA, hunt in SOC logs, and see NERC CIP mapped to real controls. Turn off safeties and blow up the plant! Vibe coded with claude and runs in your browser.
